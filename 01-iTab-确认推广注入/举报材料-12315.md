## 四、事实与理由

### 4.1 该扩展存在未向用户明示的推广行为（有完整技术证据）

1. **默认购物入口被替换为推广跳转域。**
   扩展内置的默认导航图标中，"淘宝""京东商城""天猫精选""阿里巴巴"分别指向：
   `https://taobao.coml.cc/`、`https://jd.coml.cc/`、`https://tmall.coml.cc/`、`https://1688.coml.cc/`
   —— 均为该扩展自有域名，而非官方域名。上述域名实测**全部返回 302 跳转至第三方推广点击跟踪服务**：
   `https://extdd1.browser.360.cn/browser/clk?m=<token>&st=...&dd=...&ud=...`

2. **搜索引擎链接被服务端下发的推广码强制改写。**
   扩展代码中存在如下逻辑：
   ```js
   let d = { fp: r(), tn: i, city: o };          // 上报浏览器指纹 + 推广位 + 城市
   s(d).then(i => { let s = i.data || {},
       o = s.tn || "52176495_dg&ch=2",           // 服务端下发的百度推广码
       r = s.so360;
     m.value.searchEngine.forEach(e => {
       "baidu" === e.key ? e.href = `https://www.baidu.com/s?wd=%s&tn=${o}&ie=utf-8`
                         : e.href = s[e.key] || e.href });
     t.set("app-baiduTn", o); })
   ```
   即：用户所有百度搜索请求都会被自动附加由服务端分配的推广码。实测在一台 Windows 设备上被分配的推广码为 `75144485_6_dg&ch=4`，导致浏览器历史中反复出现带推广码的地址，**用户手动删除后会自动重新生成**。

3. **上述行为均未在扩展商店页面及扩展内以任何形式向用户明示。**

### 4.3 法律依据

| 法律法规 | 条款 | 对应问题 |

《中华人民共和国广告法》 | 第十四条：广告应当具有可识别性，能够使消费者辨明其为广告 | 推广内容未标明"广告" |

《中华人民共和国反不正当竞争法》 | 第八条：经营者不得对其商品作虚假或者引人误解的商业宣传 | 默认图标指向仿冒官方域名的跳转域 |
