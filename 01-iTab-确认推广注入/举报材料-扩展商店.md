## 二、Chrome 只能选分类时，**分类怎么选**（很重要）

选错分类 = 直接进垃圾桶。优先顺序：

1. **「它违反了 Chrome 网上应用店的政策」** —— 若展开二级选项，选 **欺骗性行为 / Deceptive behavior / 误导性内容**
2. **「它未按承诺运行 / 存在意外行为」**
3. **「垃圾内容与滥用」**
4. ❌ 不要选色情、暴力、仇恨等无关分类

**另外两点**：
- 选对分类后，Google 会**实际去审扩展代码**（不是只看描述），所以这条路仍然有效；
- **同分类的多份举报会提升优先级**。在曝光文里写一句"如果你也受影响，可自行举报"是有效且安全的；**但不要组织集中刷举报**，那可能被判定为滥用举报渠道。

## 六、建议执行顺序

1. **Edge 举报页**（`reportAbuse` 直链，无需登录，最可能能写说明）→ 提交
2. **Chrome「举报滥用」** → 选对分类提交（写不了字没关系，分类会触发代码审核）
3. **Chrome `gethelp` 表单**（登录 Google 账号）→ 粘贴第三节说明
4. **Google Safe Browsing** → 举报 `jd.coml.cc` / `taobao.coml.cc` / `tmall.coml.cc` / `1688.coml.cc`（理由：冒充官方域名的欺骗性跳转）
5. **12315** → 提交 `举报材料-12315.md`
6. 最后再发帖（顺序反了会给对方时间删证据、提前应对）

> 提示：**扩展一旦下架，推广者视频里的所有链接当场失效**，这比任何舆论手段都直接。
